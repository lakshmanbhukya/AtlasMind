Problem

Natural language query orchestration leaks across the HTTP seam into route handlers, causing voice queries to execute an unmaintained duplicate pipeline that bypasses ambiguity gating and multi-tenant isolation.

Solution

Collapse voice transcription, query execution, and write approval into a single deep module behind a two-method interface, reducing route handlers to thin HTTP adapters.

Wins
  • locality: execution logic in one module
  • leverage: text and voice share engine
  • Delete 280 lines of duplicate pipelines
  • Voice queries gain tenant isolation
  • Tests exercise engine without HTTP mock

Problem

Query history persistence has no module seam, mixing write side-effects into the query executor while history retrieval, relative-time formatting, and deletion live as raw database queries inside the route handler.

Solution

Extract a deep history module that encapsulates projection, snapshot truncation, relative-time computation, and multi-tenant filtering behind a clean seam.

Wins

  • interface: callers invoke clean semantic methods

  • Eliminates raw queries from routes

Solution

Wins

  • Vector search cannot leak across tenants
  • Write admission logic leaves caller

  • Caller needs only two methods
