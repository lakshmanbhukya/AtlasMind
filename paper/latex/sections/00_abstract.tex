\begin{abstract}
Natural-language interfaces let non-technical users query MongoDB, but an underspecified request such as ``show the top products'' forces a language model to guess which numeric measure is meant, and the guess comes back as an ordinary-looking result. We call this behaviour \emph{silent assumption}. We present AMB-MQL, a conversational query-generation service for MongoDB that profiles the target collections from sampled documents, applies a deterministic, schema-grounded gate that detects metric ambiguity and returns allowlist-validated clarification cards, generates an aggregation pipeline with a single language-model call, and validates the pipeline with a stage allowlist and collection-scope check before execution, staging mutating pipelines behind single-use signed tokens. On \numTotalQueries{} human-labelled queries over three MongoDB sample datasets, the gate lowers the silent-assumption rate on lexically cued ambiguous queries from \e2eCZeroASilentLex{} to \e2eCTwoSilentLex{}, but it misses ambiguity expressed without its trigger vocabulary and raises \gateUCR{} unnecessary clarifications on clear queries. We report these limits and the design changes they suggest.
\end{abstract}
