\section{Conclusion}
\label{sec:conclusion}

In this paper, we presented AMB-MQL, an enterprise-grade conversational query-generation service for MongoDB. To resolve the \emph{silent assumption} vulnerability inherent in single-pass LLM query translators, AMB-MQL introduces a dual-tier architecture combining an in-process, sub-millisecond deterministic ambiguity gate with an AST-enforced recursive safety validator. By introspecting physical collection schemas and evaluating lexical vagueness triggers, the gate eliminates silent stochastic guessing on lexically ambiguous requests (\e2eCTwoSilentLex{} in C2 vs. \e2eCZeroASilentLex{} in C0a), providing grounded interactive clarification cards in \gateLatencyMean{} without token consumption. A recursive AST safety guard enforces an 18-stage analytical allowlist, blocking arbitrary code execution, cross-scope data leaks, and mutating stages with a 100\% adversarial block rate, while human-in-the-loop write staging protects database integrity with cryptographically signed single-use approval tokens.

Empirical evaluation on \numTotalQueries{} human-annotated queries across three MongoDB sample datasets confirms that AMB-MQL slashes overall silent assumptions on ambiguous queries by \e2eSilentAmbDelta{} ($p = \e2eSilentAmbMcNemarP{}$), while preserving 100\% pipeline validity on clear requests via user bypass. By detailing explicit system boundaries—including lexical dictionary bounds, heuristic binding misses, and four-candidate truncation—this work establishes a rigorous foundation for deterministic, schema-grounded conversational query generation in modern document-oriented database systems.
